HOUSE WARMING INVITATION — V3

This version is rebuilt as a proper mobile invitation microsite rather than a sequence of screenshots.

Flow
1. Full-screen traditional opening scene.
2. The house seal is centred on the actual CSS envelope flap.
3. Tap the seal: the seal fades, the flap opens and the date card rises out of the envelope.
4. Tap “Enter invitation” (or the revealed card) to transition into the complete invitation.
5. Scroll through: welcome → blessings → house/details → order of events → gift note/final message.

Interactive features
- Add to Calendar (.ics)
- Get Directions (Google Maps)
- Share invitation (Web Share API with clipboard fallback)
- Scroll reveal animations and section progress
- Responsive/mobile-first layout
- Reduced-motion support

The house photograph is cropped from the wireframe supplied by the user.

Open index.html in a modern browser. No build step or framework is required.
